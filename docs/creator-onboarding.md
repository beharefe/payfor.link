

# Creator Template Setup Guide

## Purpose

This document provides instructions for creators selling templates through the platform.

Templates must be configured correctly to ensure buyers can duplicate them after purchase.

Incorrect sharing settings are the most common cause of failed deliveries.

Supported platforms:

- Notion
- Figma
- Google Drive
- GitHub
- Canva
- Airtable

Each platform requires specific sharing settings.

---

# General Template Rules

All templates must meet these requirements:

publicly accessible
view-only permissions
duplication allowed

Creators must test their links before publishing.

Testing checklist:

open link in incognito browser
verify template loads
verify duplication works

If duplication fails, buyers will not be able to access the product.

---

# Notion Template Setup

## Step 1 — Prepare Template

Open the template page in Notion.

Ensure:

template is complete
placeholder content removed
instructions included

---

## Step 2 — Enable Public Sharing

Click:

Share → Publish to web

Enable the option:

Allow duplicate as template

This allows users to copy the page into their own workspace.  [oai_citation:1‡templatesfornotion.com](https://templatesfornotion.com/post/how-to-share-a-notion-template?utm_source=chatgpt.com)

---

## Step 3 — Copy Template Link

Click:

Copy link

Example link:

https://www.notion.so/workspace/template-page-id

---

## Step 4 — Enable Auto-Duplicate

Modify the link by adding:

?duplicate=true

Example:

https://www.notion.so/workspace/template-page-id?duplicate=true

This automatically opens the duplication dialog.  [oai_citation:2‡bensomething on Notion](https://bensomething.notion.site/Automatic-Duplication-Links-4f28f7c135f04a59b6c52a99f8efc2bc?utm_source=chatgpt.com)

---

## Step 5 — Test the Link

Test in a private browser:

open link
verify duplicate prompt appears
duplicate into workspace

If duplication fails:

check “Allow duplicate as template”
check page is public
check correct URL

# Figma Template Setup

## Step 1 — Prepare File

Open the Figma design file.

Ensure the template:

contains final components
organized pages
clear naming

---

## Step 2 — Set File Permissions

Click:

Share

Set access to:

Anyone with the link → Can view

---

## Step 3 — Provide Duplication Link

Figma allows duplication via:

File → Duplicate

You can also append:

/duplicate

Example:

https://figma.com/file/ABC/design-template/duplicate

---

# Google Drive Template Setup

Supported files:

- Google Docs
- Google Sheets
- Google Slides

---

## Step 1 — Open Document

Open the file in Google Drive.

---

## Step 2 — Configure Sharing

Click:

Share → Anyone with link

Set permission:

Viewer

---

## Step 3 — Test Duplication

Test:

File → Make a copy

This confirms buyers can duplicate the file.

---

# GitHub Template Setup

For code starter kits.

---

## Option 1 — Template Repository

Mark repository as template:

Settings → Template repository

Users can then click:

Use this template

This creates a new repository.

---

## Option 2 — ZIP Download

Alternative method:

Code → Download ZIP

Used for smaller projects.

---

# Canva Template Setup

Open design in Canva.

Click:

Share → Template link

Ensure:

edit access disabled
template duplication enabled

---

# Template Testing Checklist

Before publishing a product:

template opens correctly
duplication works
permissions set to view
link works in private browser

Creators should perform these checks.

# Recommended Template Structure

Creators should include an instruction page.

Example:

Welcome to your template!

Steps:
	1.	Duplicate this template
	2.	Rename your copy
	3.	Follow setup instructions

This improves buyer success.

# Common Creator Mistakes

## Sharing the wrong Notion link

Incorrect:

notion.site link

Correct:

notion.so link

---

## Forgetting duplication permission

If duplication is disabled:

buyers cannot copy template

# Best Practices for Creators

Creators should:

provide clear instructions
remove personal data
test links regularly
update templates carefully

Templates with clear instructions have fewer buyer issues.
