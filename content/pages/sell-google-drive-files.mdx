## Privacy considerations

When you share a Google Drive file as "anyone with the link," anyone who has that link can access it. The paywall controls who receives the link, but once someone has it, they can share it.

For most creators, this is acceptable. Template buyers sharing the template with one friend is a minor edge case that does not meaningfully affect revenue.

For higher-value or more sensitive files:
- Create a version of the template for paid buyers (a separate copy) and change the sharing URL after each sale
- Use a more controlled access method (like a private GitHub repo where you add buyers manually)
