## How to create a Dropbox share link

### For a single file

1. Right-click the file in Dropbox (web or desktop app)
2. Click **Share** → **Copy link**
3. In link settings, set to **"Anyone with the link"**

The resulting URL ends in `?dl=0` (preview) or `?dl=1` (direct download). For direct download, change `dl=0` to `dl=1` — buyers will get a direct download prompt rather than a Dropbox preview page.

### For a folder

1. Right-click the folder in Dropbox
2. Click **Share** → **Copy link**
3. Set to **"Anyone with the link can view"**

Buyers see the folder contents and can download individual files or the whole folder as a zip.

## How to set up the paywall

1. Copy your Dropbox share link
2. Open unseal.link → paste the URL
